# Code of Conduct

This project spans a hemisphere with dozens of languages, political systems, and institutions. That diversity is the point, not a complication to manage around.

- Engage in good faith. Disagreement about strategy, technology, or policy is expected and welcome; bad-faith mischaracterization is not.
- No harassment, discrimination, or exclusionary behavior toward any contributor on any basis.
- Correct mistakes openly. If you're wrong about a fact in a document here, say so and fix it — that's a feature of how this project works, not a failure.
- Keep commercial promotion out of technical discussions unless it's directly relevant to the repository at hand.

Reports of conduct issues can be sent to [admin@genia.ai](mailto:admin@genia.ai).
