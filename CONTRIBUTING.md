# Contributing

This repository is the hub for the AI Corridor of the Americas movement. Most of the technical work happens in the linked repositories under [GENIA Americas](https://github.com/GENIA-Americas). This repo is documentation, governance, and coordination.

## Ways to contribute here

- **Fix inaccuracies.** If a number, a legislative status, or a partner reference in this repo is out of date, open an issue or a pull request with a source. Accuracy is the whole point of this repository.
- **Improve the docs.** The manifesto, policy record, and ecosystem map should stay clear and current. PRs welcome.
- **Translate.** If you can produce or improve a Spanish or Portuguese version of any document here, that's high-value — this is a hemispheric project and the documentation should reflect that.

## Ways to contribute to the technical work

Go to the specific repository:
- [Glapagos-Backend](https://github.com/GENIA-Americas/Glapagos-Backend) for platform backend work
- [multimodal-ai-americas](https://github.com/GENIA-Americas/multimodal-ai-americas) for open research
- [ciudadania-backend](https://github.com/GENIA-Americas/ciudadania-backend) for the CiudadanIA project

Each has its own contribution norms; check that repo's README before opening a PR.

## Ground rules

- Cite a source for any factual claim about numbers, legislation, or partnerships before adding it here.
- Keep the policy language precise — see [`docs/POLICY.md`](docs/POLICY.md) for why that matters.
- Be direct and specific. This project's whole argument is that vague, imported frameworks don't serve this region well — the documentation should model the opposite.
